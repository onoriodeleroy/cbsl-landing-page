# Personal Developer Portfolio

A fully responsive, dark-themed personal portfolio website designed to showcase my web development projects and skills. 

**[Live Demo](https://onoriodeleroy.github.io/cbsl-landing-page/)**

## ✨ Features
* **Modern Dark Theme:** A sleek, professional dark UI with custom CSS variables.
* **Responsive Design:** Optimized for seamless viewing on mobile, tablet, and desktop screens.
* **Scroll Animations:** Custom JavaScript scroll-reveal effects for dynamic content loading.
* **Live Contact Form:** Integrated with Formspree for immediate, serverless email delivery.
* **Project Showcase:** Grid-based layout to cleanly display live projects (including CBL News & Scores).

## 🛠 Technologies Used
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, CSS variables, flexbox, and CSS grid.
* **Vanilla JavaScript:** DOM manipulation and event listeners for scroll animations.
* **Formspree:** Backend API for form submission handling.
* **GitHub Pages:** CI/CD and static site hosting.
